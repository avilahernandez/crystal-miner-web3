# Crystal Miner Web3 🎮

Un experimento técnico de 4 días para explorar el ecosistema Web3, construyendo una dApp (aplicación descentralizada) desde cero.

## 🎯 El Reto
Aprovechar mi amplia experiencia en desarrollo de software para dominar rápidamente el stack de Web3: conexión de billeteras, interacción con la blockchain y despliegue de dApps. Todo esto manteniendo una arquitectura limpia y ligera, sin frameworks pesados (Vanilla JS).

## 🛠️ Stack Tecnológico
*   **Frontend:** HTML5, CSS3 (Estilo Cyberpunk/Retro), Vanilla JavaScript.
*   **Web3:** Ethers.js v6, Phantom Wallet (EVM compatible).
*   **Red:** Ethereum Sepolia Testnet.
*   **Infraestructura Local:** Termux (Android), Nginx, Git.

## 🚀 Características Actuales
*   Interfaz gráfica generada 100% por código (sin imágenes, solo SVG y CSS).
*   Conexión de wallet en tiempo real.
*   Lógica de juego (minado de puntos con clics y niveles).
